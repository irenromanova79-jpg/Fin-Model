# IRIX PROFIT — учебная финансовая модель

Тренажёр для занятий по управленческому учёту и финансовому моделированию. Один HTML-файл: слева закреплённый дашборд с показателями за месяц и накопительно, справа отчёт о прибылях и убытках на 12 месяцев с параметрами прямо в строках статей. Меняете параметр — всё пересчитывается мгновенно.

Данные вымышленные: **ООО «Практикум», мебельное производство**. Реальных клиентских цифр в файле нет, его можно свободно раздавать группе.

**Часть экосистемы IRIX — умные приложения для бизнеса. Автор: Ирина Романова.**

## Как запустить

Скачайте `IRIX_PROFIT_учебная_модель.html` и откройте двойным кликом — интернет не нужен, устанавливать ничего не надо.

Для группы удобнее ссылка: положите файл в репозиторий как `index.html`, включите GitHub Pages — студенты откроют модель в один клик, без вопросов «а как это открыть».

> Через мессенджер файл часто приходит как документ и открывается во встроенном просмотрщике, где скрипты не работают. Просите скачать файл к себе или давайте ссылку.

Изменения намеренно **не сохраняются**: после перезагрузки страницы все параметры возвращаются к исходным. Каждый студент начинает с одинаковых цифр, испортить модель нельзя. Свой вариант можно выгрузить кнопкой `Скачать CSV`.

## Что показывает модель

```
Выручка
 − Прямые (производственные) затраты      параметр: % от выручки
 = Валовая прибыль                        маржинальность
 − Постоянные расходы                     параметр: ₽ в месяц
 = EBITDA
 − Проценты по кредиту и амортизация       параметр: ₽ в месяц
 = Чистая прибыль
```

Плюс точка безубыточности `(постоянные + проценты + амортизация) / норма маржинального дохода` и запас финансовой прочности.

### Горизонт

| Месяцы | Выручка | Расходы |
|---|---|---|
| янв–июн | «факт» | «факт» |
| июль | «факт» | расчёт по параметрам |
| авг–дек | прогноз: июль × темп роста | расчёт по параметрам |

Темп роста задаётся в строке «Выручка, всего», по умолчанию 0 %.

### Два режима

- **Факт + модель** — фактические месяцы показываются как есть.
- **Только модель** — все 12 месяцев пересчитываются от параметров. Ключевой режим для занятия: показывает, насколько усреднённые нормативы описывают реальность.

## Упражнения

### 1. Насколько нормативы описывают факт

Переключите режим на **«Только модель»**.

Чистая прибыль за полугодие: **3 008 620 ₽** вместо 3 253 620 ₽ — модель занижает результат на 245 тыс., то есть на 7,5 %.

*Вопрос группе:* почему усреднённый процент не воспроизводит факт? Ищите ответ в тех статьях, где расход не пропорционален выручке: ремонт оборудования скачет от месяца к месяцу, ПО платится раз в квартал, ФОТ АУП вырос в апреле. Вывод: нормативом можно описывать переменные статьи, а разовые и ступенчатые — нельзя.

### 2. Что делает рост цен на материалы

Поставьте в строке «Материалы» **40 %** вместо 35.

- Чистая прибыль июля: 778 452 → **507 878 ₽** (минус 35 %)
- Точка безубыточности июля: 3 206 088 → **3 727 778 ₽** (плюс 16 %)
- Чистая прибыль за 12 месяцев: 7 924 332 → **6 300 888 ₽**

*Вопрос группе:* выручка не изменилась ни на рубль, а прибыль упала на треть. Объясните эффект операционного рычага. Насколько нужно поднять выручку, чтобы вернуть прежнюю прибыль?

### 3. Переменная или постоянная

Снимите галочку в строке «Субподряд».

Чистая прибыль за полугодие: 3 253 620 → **5 460 681 ₽**.

*Вопрос группе:* субподряд — 8 % от выручки, то есть чистая переменная статья. А если бы бригады сидели на окладе, как изменилась бы точка безубыточности при том же объёме затрат? Разберите, почему переменные затраты безопаснее для бизнеса с нестабильной выручкой.

### 4. Прогноз и накопительный итог

Задайте в строке «Выручка, всего» темп роста **5 %** в месяц.

- Выручка за 12 месяцев: 59 790 380 → **64 094 262 ₽**
- Чистая прибыль: 7 924 332 → **9 474 759 ₽**
- Декабрь: выручка 6 849 829 ₽

*Вопрос группе:* выручка выросла на 7 %, а прибыль на 20 %. Почему? Переключайте месяцы в дашборде и следите за колонкой «Накопительно» — на ней хорошо видно, как постоянные расходы «размазываются» по растущему объёму.

### 5. Своя структура затрат

Дайте студентам задание собрать модель их собственного бизнеса или кейса: заменить проценты в блоке производства и суммы в постоянных расходах, добиться заданной рентабельности. Проверять удобно по дашборду — маржинальность, доля постоянных, запас прочности.

## Как подставить свои данные

Все цифры лежат в одной константе `DATA` в теге `<script>` в конце файла:

```js
const DATA = {
  months: ["янв","фев", ... "дек"],   // подписи 12 колонок
  factN: 6,                            // сколько месяцев считать фактом
  groups: [                            // товарные группы, 7 месяцев
    { name: "Шкафы-купе", v: [выручка×7], q: [количество×7] }, ...
  ],
  direct:    [["Материалы (сырьё, плиты, фурнитура)", [6 месяцев]], ...],
  subTotal:  2207061,                  // субподряд итогом за 6 мес.
  fixed:     [["Аренда производственного помещения", [6 месяцев]], ...],
  utilities: [6 месяцев],              // коммунальные, привязаны к аренде
  salary:    [["Директор", [6 месяцев]], ...],
  fin:       [["Проценты по кредиту", [6 месяцев]], ...]
};
```

Замените массивы — приложение само пересчитает параметры как «итого / выручка» для производства и «итого / 6» для постоянных. Названия строк подставляются в таблицу автоматически, статьи можно добавлять и убирать.

Средний чек считается как выручка группы / количество, то есть **средняя цена реализации единицы**. Если в вашей выгрузке есть количество документов реализации, чек станет чеком на сделку — поменяется только знаменатель.

## Оформление и интерфейс

Три темы, переключаются кнопкой `Тема`: тёмно-золотая (по умолчанию), светлая, изумрудная. Все цвета — CSS-переменные в блоке `:root` в начале файла.

Подсветки в таблице: **ячейки ввода** — параметры, которые можно менять; **тонированные колонки** — месяцы, посчитанные моделью, а не взятые из факта.

Первые две колонки (статья и параметр) закреплены при горизонтальной прокрутке, шапка таблицы и дашборд — при вертикальной.

Кнопка `Вернуть факт` сбрасывает все параметры к исходным значениям — удобно между группами.

## Технические детали

- Один файл ~28 КБ, ванильный JS, без библиотек, CDN и интернета.
- Браузеры примерно с 2023 года: Chrome, Edge, Яндекс.Браузер, Firefox, Safari. На старых шапка будет без размытия — остальное работает.
- Не использует хранилище браузера: состояние живёт только в открытой вкладке.
- `Скачать CSV` — с BOM и разделителем `;`, Excel открывает без мастера импорта. В Safari скачивание с локального файла иногда блокируется, с сайта работает.
- `Печать` — A4 landscape, дашборд уходит на первую страницу, таблица на остальные. В Firefox включите «Печать фона», иначе пропадут заливки.
